    Keyboard shortcuts

    Ctrl K or Cmd K
    Open the jump palette, from anywhere
    /
    Open the jump palette
    j
    Next memory in the list
    k
    Previous memory in the list
    e
    Edit the content
    F
    Expand or restore the editor
    Esc
    Close a dialog, or leave the expanded editor
    Ctrl S or Cmd S
    Save the open memory
    Ctrl B or Ctrl I
    Bold or italic in the content (Markdown); Cmd on macOS
    ?
    Show these shortcuts

    Single-key shortcuts are ignored while typing in a field or while a dialog is open.
